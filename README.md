# 截图翻译

截图翻译是一个 iOS 快捷指令：截取屏幕、识别文字，通过 Google 翻译译成中文，结果以弹窗显示并自动复制到剪贴板。全部使用系统自带动作，无需安装任何第三方 App。

## 安装

在 iPhone 上打开 [iCloud 链接](https://www.icloud.com/shortcuts/f9d4dd8784034492ae25baf71b78d930) 安装。

安装后，建议为它绑定一个快捷触发方式：操作按钮、轻点背面或悬浮球，后两者可在 **设置** > **辅助功能** > **触控** 中设置。

## 使用

**翻译整个屏幕**：直接运行快捷指令。它会自动截屏并翻译屏幕上的文字，竖屏横屏都可用。

**翻译选中区域**：手动截图，轻点缩略图进入编辑，拖动裁剪框框选目标区域，然后在共享菜单中选择**截图翻译**。

结果默认逐行对照展示：原文行在上、译文行在下，两行一组，组间空行分隔。屏幕上混有多种语言时，各行分别与译文配对。弹窗可滚动、可选中，内容同时自动复制到剪贴板。识别结果中的界面杂项（时间、电量、图标残迹）和已是中文的行会被自动过滤。

**切换显示模式**：快捷指令的第一个动作是一个数字开关。在快捷指令编辑器中把它从 1 改为 0，结果只显示译文，保留原文的段落结构。

如果没有识别到值得翻译的文字，你会收到一条通知；如果翻译失败，识别出的原文会复制到剪贴板，并同样以通知提示。

## 从源码构建

```sh
python build.py
```

产物为 `截图翻译.shortcut`。如果某个 App 的状态栏或底部工具栏总是混进翻译结果，把 `build.py` 顶部的 `TOP_INSET`、`BOTTOM_INSET` 调大后重新构建，它们是自动截屏后上下各裁掉的像素数，缺省都是 0。

iOS 不允许直接导入未签名的快捷指令文件，需要借助辅助快捷指令完成导入：

1. 安装 [Shortcut Installer](https://www.icloud.com/shortcuts/9918c1c856c049b4beb7918904b1fe0d)，它由本仓库的 `installer.py` 生成。
2. 把 `截图翻译.shortcut` 传到 iPhone（AirDrop、微信、Telegram 均可）。
3. 选中该文件，轻点 **共享** > **Shortcut Installer**。
