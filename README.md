# 截图翻译

iOS 快捷指令：截屏 → OCR → 文本清洗 → Google 翻译 → 复制并显示。
不装任何第三方 App，全部使用系统自带动作。`.shortcut` 文件由 Python 脚本生成，可在任意平台构建。

建议配合 **操作按钮** 运行快捷指令，或者使用悬浮球、轻点背面等辅助功能。(设置 → 辅助功能 → 触控)

## 用法

两条路线，运行时自动区分：

- **直接运行**：自动截屏，按比例裁掉顶部通知栏和底部导航栏，翻译整屏内容。
- **选区翻译**：手动截图 → 点缩略图 → 拖裁剪框 → 分享 → 选本快捷指令，只翻译你框选的区域

译文自动复制进剪贴板，并用快速查看弹出（标题固定为「翻译结果」），可滚动可选中，段落结构保留。翻译空手而归时，改为复制原文并通知。清洗后凑不满 3 个字母的（图标残迹、纯数字之类）不翻译，直接通知收场。

## 安装

未签名的 `.shortcut` 不能直接导入——iOS 15 起签名只能出设备。`installer.py` 生成的 `导入快捷指令.shortcut` 把这件事收成一个动作：接住分享来的文件，发给远程签名服务（[Shortcut Source Helper](https://routinehub.co/shortcut/10060/)「Remote Sign」的同款通道），签好直接进快捷指令库。

1. 安装 [Shortcut Source Tool](https://www.icloud.com/shortcuts/e6fdda8687cf49b4a4c965995b70c051) 和它依赖的 [Shortcut Source Helper](https://www.icloud.com/shortcuts/7125fde0360a49f5994d02fb6d1b1fbd)——只为引导下面这一步，装完都可以删
2. 按「首次导入」把 `导入快捷指令.shortcut` 装进去

## 日常导入

把 `.shortcut` 传到 iPhone（微信 / AirDrop / 文件均可），在「文件」里长按 → **共享** → **导入快捷指令**。

## 首次导入

`导入快捷指令` 自己也是未签名的，得靠 Shortcut Source Tool 引导一次：

1. 把 `导入快捷指令.shortcut` 存进「文件」，然后在快捷指令 App 里运行 Shortcut Source Tool
2. 在 **Get Shortcut Source from** 菜单里选 **📝 File**，选中刚存的文件（**💫 Shortcut** 搜的是已装进库的，此时只会得到 "No shortcuts found"）
3. 选择 **Edit/Restore Source**
4. 选择 **Skip**
5. 点击右上角 ☑️ 按钮，为 shortcut 命名后点击 **Done**
6. 选择 **Remote Sign**，签名完成后即加入快捷指令库

## 自定义

改 `build.py` 后重新运行 `python build.py` 即可：

- 裁剪比例：`source()` 里两个 math 动作的 `13E-2`（顶部裁掉 13%）和 `735E-3`（保留 73.5%）。E 记数法是为了避开小数点的地区解析歧义，小数写法会被导入工具拦下
- 目标语言：文件头部的 `TARGET`
- 起译门槛：`MIN_LETTERS`，清洗后剔除数字、标点、空白，剩余字符数超过它才翻译
- 弹窗标题：`TITLE`
- 清洗规则：文件头部的正则表（去噪 / 去重 / 空行折叠 / 断行合并 / 段落合并）

## 原理

`.shortcut` 是二进制 plist，`build.py` 直接构造动作数组并序列化，落盘前自检（UUID 引用完整性、条件块配平、变量占位符对齐）。`installer.py` 复用同一套构件和自检。

OCR 清洗链按序执行五步正则替换：

1. **去噪**：删掉不需要翻译的部分——装饰箭头和分隔线、图标被 OCR 成的字符残迹（独占一行、粘行首如 `66 标题文字`、挂行尾如 `About me ···`）、时间电量之类的纯数字行、`164 cm` 这种数字加单位独占一行的，以及含中文的整行——中文残留会让系统把整段判为中文而跳过翻译（日、韩、泰、越、高棉文不受影响）
2. **去重**：同一行文本重复出现只保留一次（如 UI 按钮词）
3. **空行折叠**：段落边界折叠为哨兵字符，翻译后还原，保住段落结构
4. **断行合并**：行尾无标点且下行小写开头的 OCR 断行拼回同一句，显著提升译文质量
5. **段落合并**：泰语、高棉语、日文、韩文没有大小写可依，改用行长判断——满行且行尾无句号，说明下一行是同一句的续行

## 翻译

清洗完的文本全部发给 Google 的公开端点，**一律出设备**，介意的话别用。不用系统翻译（本可不出设备）是因为它对不支持的语言**不报错，退化成罗马字音译**——`បើសិនអ្នកល្បី...` 变成 `Chesian Phuharinthikat...`，有值不算失败，在快捷指令里兜不住。

走 `translate_a/single` 端点，文本放 POST 表单（不进 URL，长文本不会撑爆长度限制），`dj=1` 让响应变成 `{"sentences": [{"trans": ...}]}`。`sentences` 是字典列表，直接取键会弹「选取项目」，所以用「重复」逐项取 `trans` 再拼接。换行和段落哨兵原样返回，段落结构不受影响。
